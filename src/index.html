Как строится план

  • Фазы задачи идут по порядку стеков: C++ → Питон → Дотнет → Фронт. Порядок меняется в карточке задачи (↑/↓), он попадает в расчёт сразу.
  • C++ и Питон идут параллельно, если у них разные исполнители. Дотнет стартует после того, как закончатся оба. Если исполнитель один — строго по очереди.
  • Не больше двух задач на исполнителя одновременно. Третья ждёт, когда освободится слот.
  • Правило 3×: две задачи могут идти у одного человека параллельно, только если часы их фаз различаются втрое и больше (крупный блок и мелкий).
  • Отпуска: фаза встаёт на паузу на дни отсутствия, срок сдвигается вправо, часы не теряются.
  • Даты из файла — ограничения. Старт не раньше самой поздней из дат: фактического начала (факт важнее всего), «Не раньше» (готовность ТТ) и базового начала. Если задано только базовое окончание — начало считается назад от него.
  • Галочка «Не раньше плана» (включена) учитывает базовые даты. Снимите — задачи поедут как можно раньше, останутся только занятость исполнителей и готовность ТТ.
  • Приоритет 1 — самый высокий. Планировщик раздаёт ресурсы в порядке приоритета; если более приоритетная задача всё равно стартует позже, появляется предупреждение.
  • Жёлтая плашка «Задача» сверху — предупреждения; клик по предупреждению подсвечивает задачу на диаграмме.
  • Фильтр над диаграммой: по исполнителю и по части названия (складываются). Фильтр только скрывает строки — расписание не пересчитывается. Клик по предупреждению снимает фильтр, чтобы показать задачу.
  • Горячие клавиши: Esc — снять выбор, +/− — масштаб, T — к сегодняшнему дню, / — поиск по названию, ? — эта справка.
