# gantt — планировщик Гант и конвертер РКК

Одностраничные офлайн-приложения, собираются из `src/` в `dist/`.

## Команды

```bash
npm run build      # dist/Gantt.html и dist/Конвертер.html (SheetJS вшит)
npm run fixtures   # тестовые xlsx в tests/fixtures (синтетика) + local/ (копии реальных)
npm test           # Playwright E2E, 207 тестов
npm run test:headed
```

## Правила репозитория (публичный)

- **Реальные данные пользователя не коммитить.** `РКК.xlsx` и `Шаблон.xlsx`
  копируются в `tests/fixtures/local/`, который в `.gitignore`; тесты на них
  пропускаются, если файла нет. Перед коммитом проверять индекс.
- **Фикстуры генерируются кодом** (`tests/make-fixtures.mjs`,
  конструкторы в `tests/helpers.mjs`) — править генератор, а не бинарники.
- Секреты, токены, `.env` в репозиторий не добавлять.
- Тесты идут против собранного `dist/` по `file://`, поэтому после правок
  в `src/` сначала `npm run build`, потом `npm test`.

## Устройство

- `src/calendar.js` — рабочий календарь (пн–пт, 8 ч, праздники РФ 2026–2027).
- `src/schedule.js` — планировщик: лимит 2 задачи на исполнителя, правило 3×,
  параллельные C++/Питон у разных исполнителей, границы дат (факт > «Не раньше»
  > базовое начало), отпуска.
- `src/parse.js` — разбор шаблона, `src/converter*.js` — РКК → шаблон,
  `src/stacks.js` и `src/dates.js` — общие утилиты обоих приложений.
- `tests/classes-*.spec.mjs` — покрытие классов эквивалентности входа.
